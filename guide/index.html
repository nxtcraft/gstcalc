GST Formulas

Add GST: GST Amount = Base × Rate / 100 → Total = Base + GST Amount

Remove GST (reverse): Base = Total ÷ (1 + Rate/100) → GST Amount = Total − Base

Example — Add 18%: Base ₹1,000 → GST ₹180 → Total ₹1,180.

Example — Remove 18%: Total ₹1,180 → Base = 1180 ÷ 1.18 = ₹1,000 → GST = ₹180.

CGST, SGST and IGST Explained

GST is a dual tax. The same rate is shared between the central and state government:

  • Intra-state transaction (same state): 18% GST = 9% CGST + 9% SGST.
  • Inter-state transaction (different states): 18% GST = 18% IGST (no split).

Both give the same final price to the buyer. The split only matters for which government receives the revenue.

Frequently Asked Questions

How is GST calculated in India?

Add GST: GST Amount = Base × Rate / 100; Total = Base + GST. Remove GST: Base = Total ÷ (1 + Rate/100); GST = Total − Base.

What is CGST, SGST and IGST?

Intra-state: CGST = SGST = GST rate / 2. Inter-state: IGST = full GST rate. Buyer pays the same price either way; only the government receiving the tax differs.

What are the GST slabs in India?

0% (essentials), 5% (basic goods), 12% (processed goods), 18% (most goods/services), 28% (luxury/demerit goods). Some items like gold have special 3% rate.
